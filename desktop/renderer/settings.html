설정

캐릭터

선택한 캐릭터에 맞춰 외형과 말투, 기본 대사가 바뀌어요. 「문구」에서 직접 수정한 대사는 유지돼요.

「＋ 새 캐릭터」에서 이름, 이미지, 말투를 설정할 수 있어요. 각 카드의 ✎ 버튼으로 이미지와 대사를 수정할 수 있어요.

AI 및 모델

사용 중인 AI를 확인하고 작업별 모델을 설정해요.

연결된 AI

현재 사용 중인 AI를 연결 해제하면 AI 기능이 중지돼요. 할 일과 알림 기능은 계속 사용할 수 있어요.

작업별 모델

용도에 맞는 모델을 선택해 주세요. 변경 사항은 자동으로 저장돼요.

앱 정보

언어

화면 문구, 캐릭터 이름과 대사, AI 답변에 사용할 언어를 선택해요. 변경 사항은 바로 적용돼요.

브리핑에 포함할 정보

선택한 출처의 정보를 확인하고 브리핑에 포함해요.

로컬 정보 접근

선택한 작업 기록과 폴더만 읽어요. 기본적으로 꺼져 있어요.

좌측 메뉴 표시

사용할 메뉴를 체크하고, 메뉴를 선택한 뒤 위로/아래로 이동해서 순서를 바꾸세요.
설치, 개요는 고정이며 다른 메뉴는 항상 개요 아래에 표시돼요.

오늘 할 일 알림

캐릭터가 오늘 할 일 등록을 안내하고 남은 할 일을 알려 줘요. AI 연결 없이도 사용할 수 있어요.

일정 알림

연결된 캘린더의 일정이 시작되기 전에 캐릭터가 춤추며 알려 줘요. 알림 시점을 여러 개 선택하면 각각 알림을 받아요.

일정 시작 몇 분 전에 알릴지 숫자로 입력하세요. 예: 20 → 20분 전, 1440 → 하루 전(24시간).

근무 시간

설정한 근무 요일과 시각에 맞춰 출근, 점심, 퇴근을 알려 줘요.

출근 시각 이후에는 아침 인사를, 점심 시각부터 1시간 이내에는 점심 영상과 함께 알림을 전해요. 퇴근 10분 전에는 일정 알림 영상으로 퇴근을 안내해요. 각 알림은 하루에 한 번만 표시되며, 앱을 다시 실행해도 반복되지 않아요.

날씨

선택한 지역의 날씨를 캐릭터가 알려 줘요. AI 연결 없이 사용할 수 있고, 지역을 선택하면 알림을 설정할 수 있어요.

    지정 시각

    캐릭터를 더블클릭해 대화 입력창을 열고, 「＋」 메뉴에서 「오늘 날씨?」를 선택하면 바로 확인할 수 있어요. 지역 검색 시에는 입력한 검색어를, 날씨 조회 시에는 선택한 지역의 위도, 경도를 Open-Meteo에 보내요. 기기의 GPS 위치는 사용하지 않아요.

    날씨 제공: Open-Meteo, 데이터 CC BY 4.0

    자동 머지할 저장소

    등록한 저장소에서는 앱이 처리하는 PR을 검사 통과 후 추가 승인 없이 병합해요.

    자동 머지 설정을 사용하려면 Claude Code 또는 Codex에 로그인해야 해요. 「설치」 화면에서 연결 상태를 확인해 주세요.

    문구

    상황별로 캐릭터가 사용할 대사를 설정해요. 여러 줄을 입력하면 그중 한 줄을 골라 사용해요. {title} 같은 변수에는 실제 값이 자동으로 들어가요. 각 문구에서 지원하는 변수만 사용할 수 있어요. 입력란을 비우면 기본 대사를 사용하고, 저장하면 바로 적용돼요.

    행동 지침

    AI의 말투, 답변 형식, 작업 방식을 설정해요. 켠 지침은 선택한 범위의 대화, 브리핑, 코드 작업에 적용돼요. 지침이 충돌하면 목록 아래쪽에 있는 지침을 우선해요. 대화에서 학습한 사용자 정보와는 별도로 관리해요.

    연결 상태

    연결에 문제가 있으면 「설치 안내」를, 새로 연결하려면 「연결하기」를 눌러 주세요. 패널의 설치 화면에서 연결을 설정할 수 있어요.

    「연결 해제」를 누르면 앱에 저장된 해당 서비스의 연결 정보와 토큰, 주소가 삭제돼요. Claude Code에 별도로 등록한 MCP 서버 연결은 유지돼요.
