# 시사 개인용 v0.5.0 (Windows)

2026-11-18 한국 시간 기준 `custom/euiseon` 브랜치의 개인용 변경을 배포합니다. 공식 소스 v0.4.0 대비 변경 사항입니다. `추가`는 새 기능, `개선`은 기존 기능의 보완, `변경`은 배치나 기본 설정 변경을 뜻합니다.

## 「할 일」 메뉴

- `추가` **「날짜 변경」의 하루/기간/반복 설정** — 할 일의 예정일을 하루/기간/요일별 반복으로 설정할 수 있습니다. 기간으로 설정된 할 일은 1개의 할 일로 관리하고, 반복 일정은 해당 요일에 새로 생성되는 할 일이므로 각각 완료할 수 있도록 관리합니다.
- `변경` **할 일 목록을 예정일 기준으로 분류** — 아직 완료하지 않은 할 일을 예정일에 따라 미완료 / 오늘 / 이번주 / 나중에 / 날짜 없음으로 묶어 표시합니다. 「미완료」에는 예정일이 지난 할 일, 「이번주」에는 내일부터 이번 일요일까지의 할 일, 「나중에」에는 다음주 이후의 할 일이 표시됩니다. 기간으로 설정된 할 일은 완료하기 전까지 해당 기간 동안 「오늘」에 표시됩니다.
- `개선` **순서를 바꿔도 예정일과 우선순위 유지** — 같은 날짜로 표시된 할 일끼리 드래그하거나 키보드로 순서를 바꿀 수 있습니다. 순서만 바뀌며, 기존에 설정한 우선순위와 예정일/반복 설정은 그대로 유지됩니다.
- `추가` **「관련없음」 처리와 별도 목록 관리** — 「관련없음」으로 처리한 할 일은 휴지통과 별도의 목록에 보관하고, 같은 할 일이 다시 자동 등록되지 않도록 제외 기록을 남깁니다. 필요하면 할 일 목록으로 복원할 수 있습니다. 제외 기록을 영구 삭제하면 같은 할 일이 다시 자동 등록될 수 있습니다.
- `개선` **「최근 7일 완료」의 정렬 기준** — 최근 7일 동안 완료한 할 일은 가장 최근에 완료한 항목부터 표시합니다. 과거 데이터에 완료 시각이 없으면 완료 일지에 남은 시각을 사용하고, 일지도 없으면 마지막 수정 시각 또는 생성 시각을 대신 사용합니다.

## 「통계」 메뉴

- `추가` **완료 기록과 집중 기록을 모아 보는 「통계」 메뉴** — 기존 「할 일」과 「오늘 할 일」에 나뉘어 있던 통계를 별도의 「통계」 메뉴로 모았습니다. 「통계」에서 주간/월간 조회 기간을 선택하면 해당 기간에 완료한 할 일과 집중한 시간을 함께 확인할 수 있습니다.
- `추가` **날짜별 완료 개수 표시** — 주간 화면에서는 날짜별로 완료한 할 일의 개수를 선 그래프로 확인할 수 있습니다. 월간 화면에서는 달력 형태로 배치된 각 날짜 아래에 완료 개수를 표시합니다.
- `개선` **집중 기록을 오전/오후 도넛 차트로 표시** — 날짜별 집중 시간은 오전/오후를 서로 다른 색으로 구분한 도넛 차트로 표시합니다. 하루 8시간을 100%로 계산하며, 8시간을 넘게 집중한 날은 100%를 넘는 비율과 초과 표시를 함께 보여줍니다.
- `추가` **날짜를 선택해 일별 활동 확인** — 차트에서 날짜를 선택하면 그날 완료한 할 일, 그날 진행 중 상태였던 할 일, 오전/오후에 집중한 시간을 확인할 수 있습니다. 그날 진행하다가 완료한 할 일은 완료 목록에만 표시합니다. 진행 중 기록은 이 기능을 사용하기 시작한 이후부터 쌓이며, 이전 기록은 복원하지 않습니다.
- `개선` **집중 시간의 줄바꿈** — 통계 요약 카드와 오전/오후 집중 시간 카드에서 시간과 분이 함께 표시되는 경우, 「18시간」과 「20분」처럼 각각 한 줄씩 표시해 숫자와 단위를 함께 읽을 수 있도록 했습니다.
## 패널 상단 「집중하기」 / 캐릭터 우클릭 메뉴

- `변경` **집중 조작 버튼을 패널 공통 상단으로 이동** — 기존 「할 일」과 「오늘 할 일」에서 사용하던 집중 조작 버튼을 공통 상단으로 옮겼습니다. 패널에서 어떤 메뉴를 보고 있든 상단에서 집중을 시작하거나 일시정지/재개/종료할 수 있습니다.
- `추가` **캐릭터 우클릭 메뉴의 「집중 시작」** — 진행 중이거나 일시정지한 집중 세션이 없을 때, 캐릭터를 우클릭해 「집중 시작」을 선택할 수 있습니다.

## 「개요」 메뉴의 최근 브리핑

- `개선` **브리핑에 포함된 할 일을 표로 표시** — 최근 브리핑에 포함된 할 일 중 앱의 할 일 항목과 연결된 목록은 예정일 / 상태 / 할 일 표로 표시해, 언제 해야 하는 일인지와 현재 상태를 함께 확인할 수 있도록 했습니다.
## 캐릭터 알림 말풍선

- `추가` **확인하지 않은 알림 저장** — 확인이 필요한 알림은 「확인」을 누르기 전까지 남겨두며, 앱을 종료했다가 다시 실행해도 볼 수 있습니다.
- `추가` **여러 알림을 페이지로 넘겨 보기** — 알림이 여러 개면 페이지를 넘겨 하나씩 확인할 수 있습니다.
- `개선` **일시적인 안내는 보관 대상에서 제외** — 정보를 모으는 중이라는 안내나 앱 시작 인사처럼 잠깐 보여주는 메시지는 확인할 알림 목록에 남기지 않습니다.
- `개선` **긴 할 일 알림과 출처 표시** — 할 일 알림의 제목이 길면 여러 줄로 표시하고, 표시 영역을 넘는 내용은 알림 안에서 스크롤해 볼 수 있도록 했습니다. 날짜와 알림의 출처도 함께 표시하며, 출처명은 한글로 보여줍니다.

## 개인용 Windows 설치 및 데이터 이전

- `추가` **공식 앱과 별도로 설치하는 ShisaPersonal 배포본** — 개인용 앱은 ShisaPersonal이라는 이름으로 공식 앱과 별도로 설치할 수 있습니다. 개인용 데이터는 기본적으로 %USERPROFILE%\.shisa-personal 폴더에 저장합니다. 앱과 백그라운드 프로그램이 통신할 때는 기본 포트 47834를 사용합니다.
- `변경` **개인용 앱의 공식 업데이트 안내 비활성화** — 개인용 앱에서는 공식 앱의 새 버전을 확인하거나 업데이트를 안내하지 않습니다. 개인용 새 버전이 나오면 해당 설치 파일을 받아 직접 업데이트합니다.
- `추가` **기존 데이터와 캐릭터를 가져오는 이전 스크립트** — 기존 데이터와 캐릭터를 가져오려면 별도의 이전 스크립트를 실행해야 합니다. 스크립트는 원본을 보존하고 백업을 만든 뒤 개인용 폴더에 복사합니다. 개인용 데이터나 설정 폴더가 이미 있으면 덮어쓰지 않고 중단합니다. 이전을 마친 뒤 각 앱에서 변경한 내용은 다른 앱에 자동으로 반영되지 않습니다.

## 설치와 업데이트

- Windows 10 이상 x64: `ShisaPersonal-0.5.0-Setup.exe`를 실행합니다.
- 휴대용: `ShisaPersonal-0.5.0-win-x64.zip`을 풀고 `ShisaPersonal.exe`를 실행합니다. EXE만 따로 복사하면 실행되지 않습니다.
- 파일 이름과 앱 정보에 0.5.0을 표시하며, 앱 실행 파일의 Windows 제품/파일 버전에도 반영합니다.
- 개인용 앱은 `ShisaPersonal`, 데이터 폴더 `%USERPROFILE%\.shisa-personal`, 포트 `47834`를 사용합니다. 공식 앱의 업데이트 안내는 비활성화됩니다.
- 업데이트 전 알림 영역에서 개인용 시사를 종료한 뒤 새 설치 파일을 실행하세요. 자동 업데이트는 제공하지 않습니다.
- 코드 서명은 없습니다. Windows SmartScreen 경고가 표시될 수 있습니다.
- 캐릭터 원본 그림·영상과 개인 데이터는 배포 파일에 포함하지 않습니다. 기존 데이터의 최초 이전 방법은 [개인용 안내](https://github.com/Euiseon-Lee/shisa-agent/blob/shisa-0.5.0-windows/docs/personal-preview.md)를 참고하세요. 기존 대상 폴더는 덮어쓰지 않습니다.
- 과거 완료 시각은 일지가 없으면 수정/생성 시각으로 보완하며, 진행 중 이력은 기록을 시작한 이후부터 조회됩니다.

## 빌드 재현

Node.js 24 이상과 npm이 있는 Windows에서 저장소 루트 기준으로 실행합니다.

```powershell
npm --prefix desktop ci
$env:SHISA_RELEASE_REPO = 'Euiseon-Lee/shisa-agent'
$env:SHISA_RELEASE_TAG = 'shisa-0.5.0-windows'
node windows/dist-win.mjs --personal --arch=x64
```

버전은 `desktop/package.json`과 `desktop/package-lock.json`에서 관리합니다. 이번 배포에서는 잠금 파일의 Node.js 요구 버전도 package.json과 같은 `>=24`로 맞췄습니다.

## 기존 캐릭터가 기본 원형으로 보이는 경우

0.5.0 설치 파일에는 기존 캐릭터 그림/영상이 포함되지 않습니다. 공식 0.3.3을 사용하던 PC에서도 개인용 데이터 폴더에 캐릭터 파일을 복사하지 않았다면 기본 원형이 표시됩니다.

개인용 앱을 이미 실행해 데이터가 만들어졌다면 전체 데이터 이전 대신, 저장소의 `custom/euiseon` 브랜치 최신 소스에서 아래 명령으로 캐릭터 파일만 복사합니다(Node.js 24 이상). 공식 앱 설치 경로가 다르면 `--assets` 값을 실제 경로로 바꾸세요.

```powershell
node windows/restore-character-assets.mjs --assets="$env:LOCALAPPDATA\Shisa\app-0.3.3\resources\assets"
```

기존 개인용 DB/설정과 이미 있는 캐릭터 파일은 덮어쓰지 않습니다. 복사 후 알림 영역에서 개인용 앱을 종료하고 다시 실행하면 캐릭터를 읽습니다. 캐릭터가 정상 표시되는 것을 확인하기 전에는 공식 0.3.3 설치 폴더를 보관하세요.

이 명령은 배포 이후 제공하는 복구 도구이며, 0.5.0 EXE에 포함된 자동 이전 기능은 아닙니다.
