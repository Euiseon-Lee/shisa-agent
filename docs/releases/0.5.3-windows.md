# 시사 개인용 v0.5.3 — Windows

v0.5.2 대비 변경 사항입니다. `추가`는 새 기능, `개선`은 기존 기능 보완, `변경`은 동작 변경을 뜻합니다.

## 「캐릭터」의 할 일 알림과 브리핑

- `변경` **이번 주까지의 할 일만 안내** — 오늘과 이번 주에 예정된 할 일, 날짜가 지난 미완료 항목만 안내합니다. 다음 주 이후의 항목과 날짜가 없는 항목, 완료된 항목은 제외합니다.
- `개선` **알림 개수와 목록 일치** — 알림에 표시하는 개수와 상세 목록에 같은 기준을 적용했습니다.
- `변경` **브리핑 결과를 하나의 알림으로 표시** — 새 할 일 안내와 브리핑 요약이 따로 나오지 않도록 하나로 정리했습니다. 다시 브리핑하면 이전 요약 알림을 갱신합니다.
- `개선` **현재 할 일을 기준으로 요약** — 현재 저장된 미완료 항목을 기준으로 안내해, 다음 주 이후의 할 일이 요약에 섞이지 않도록 했습니다.

## 레이아웃 통일

- [개요 / 통계] 숫자와 시간을 보여주는 카드의 제목은 왼쪽, 값은 오른쪽에 표시합니다. 추가 설명은 아래쪽에 왼쪽 정렬합니다.
- [개요 / 통계] 제목이나 설명이 여러 줄로 표시되어도 함께 나오는 카드들의 높이를 같게 맞춥니다.
- [개요 / 통계] 카드가 좁아지면 「집중 기록이 / 있는 날」, 「하루 평균 / 집중 시간」처럼 관련된 단어끼리 묶어 줄을 나눕니다.
- [개요] 진행 중 프로젝트가 1개면 이름을 표시하고, 여러 개면 「프로젝트명 외 2개」처럼 표시합니다. 이름이 길면 뒷부분을 줄여 표시하며, 나머지 개수는 항상 보입니다.
- [통계] 화면이 넓으면 카드 4개를 한 줄로, 중간 너비에서는 2개씩 두 줄로, 좁으면 1개씩 표시합니다.
- [통계] 오전과 오후 집중 시간 카드가 나란히 들어가지 않으면 위아래로 표시합니다. 「1시간 37분」처럼 시간과 분은 한 줄로 유지합니다.
- [통계] 화면이 좁아져도 차트의 날짜와 기록이 겹치지 않도록 차트 안에서 좌우로 스크롤할 수 있습니다. 기록이 없는 날의 날짜도 같은 줄에 맞춰 표시합니다.
- [통계] 도넛 차트에 마우스를 올렸을 때 가운데까지 색이 채워져 보이던 문제를 수정했습니다.
- [할 일] 제목이나 날짜 정보가 다음 줄로 내려가도 점 세 개 메뉴는 항상 해당 할 일의 오른쪽 끝에 표시합니다.
- [개요] 최근 브리핑 표에서 「예정일」과 「상태」는 열 제목과 내용을 모두 가운데 정렬합니다. 할 일 내용은 왼쪽 정렬을 유지합니다.
- [캘린더 / 통계] 공간이 부족하면 「오늘」과 보기 선택 버튼이 함께 다음 줄로 내려가고, 그 줄의 오른쪽에 표시됩니다.
- [공통] 밝은 테마의 기본 카드 배경을 더 밝은 회색으로 통일했습니다. 오전과 오후 집중 시간 카드, 캘린더 본문의 배경은 유지합니다.
- [공통] 상단의 집중하기부터 닫기 버튼까지 오른쪽에 모아 표시합니다. 창이 넓어져도 버튼 사이 간격은 일정 범위 안에서 유지합니다.
- [공통] 새로고침은 항상 원형 화살표 아이콘으로 표시합니다. 작업 세션과 집중하기도 공간이 좁아지면 아이콘으로 표시하며, 마우스를 올리면 기능 설명을 확인할 수 있습니다.
- [공통] 「방금 갱신」 같은 갱신 시각은 공간이 있을 때 표시하고, 버튼이 들어갈 공간이 부족하면 숨깁니다.
- [공통] 일시정지, 다시 시작, 그만하기는 화면 너비와 관계없이 아이콘으로 표시합니다. 평소에는 배경 없이 표시하고, 마우스를 올렸을 때 강조합니다.
- [공통] 작업 세션은 문서와 연필, 복원은 시계와 되돌림 화살표, 반복은 각진 두 화살표로 바꿔 기능을 구분하기 쉽게 했습니다.
- [공통] 집중 시작이나 일시정지 등의 요청에 실패하면 상단 버튼 아래에 오류 안내를 표시합니다. 긴 안내 문구 때문에 버튼 배치가 흐트러지지 않도록 했습니다.

## 문구 변경

- [개요 / 브리핑 / 알림] 「승인 대기 중 코드」를 「승인 대기 코드」로 간결하게 변경했습니다.

## 개발 앱 구분

- `추가` **개발용 표시** — 테스트용으로 실행한 개발 앱은 창 제목과 화면 상단에 「개발용 0.5.3」을 표시해 일반 앱과 구분할 수 있습니다.
