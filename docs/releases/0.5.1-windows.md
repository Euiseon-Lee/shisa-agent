# 시사 개인용 v0.5.1 (Windows)

v0.5.0 대비 변경 사항입니다. `추가`는 새 기능, `개선`은 기존 기능의 보완을 뜻합니다.

## 「캘린더」 메뉴의 「색 바꾸기」

- `추가` **원하는 색 직접 선택** — 캘린더 이름 옆 「⋯」 또는 우클릭으로 「색 바꾸기」를 열면, 기존 기본 색상표와 함께 색상 선택기를 사용할 수 있습니다.
- `추가` **HEX 색상 코드 입력과 미리보기** — `#AABBCC` 형식의 6자리 코드를 입력하고 「적용」을 누르면 원하는 색으로 저장합니다. `#` 없이 입력해도 됩니다. 잘못된 코드는 저장하지 않고 안내하며, 「자동」을 누르면 자동 색상으로 돌아갑니다.
- `개선` **사용자 지정 색 유지** — 선택한 색은 재실행 후에도 유지되고, 캘린더 이름 옆 색상 점/일정/일정 상세 카드/개요의 캘린더 목록에 반영됩니다. 종일 일정 막대는 배경색 밝기에 따라 글자색을 조정합니다.

## 「캘린더」 메뉴 상단의 기간 제목

- `개선` **기간의 양쪽에 월 표시** — 같은 달이어도 `2026년 11월 16일 ~ 11월 22일`처럼 시작일과 종료일 모두 월/일을 표시합니다.
- `개선` **연도를 넘으면 양쪽에 연도 표시** — `2026년 12월 28일 ~ 2027년 1월 3일`처럼 표시합니다. 월/일 앞에 0을 붙이지 않습니다.

## Windows 작업 표시줄 고정 아이콘

- `개선` **고정 아이콘도 선택한 캐릭터로 표시** — 「앱 아이콘도 캐릭터로」 설정에 따라 창/트레이뿐 아니라 개인용 앱의 기존 작업 표시줄 고정 바로가기와 시작 메뉴/바탕 화면 바로가기 아이콘도 갱신합니다.
- `개선` **업데이트 후 바로가기 유지** — 설치형 앱의 바로가기가 버전별 폴더가 아닌 고정 실행 경로를 사용하도록 수정했습니다. 개인용 앱의 Windows 식별자도 공식 앱과 구분합니다.

## 설치와 업데이트

- Windows x64 설치 파일: `ShisaPersonal-0.5.1-Setup.exe`.
- 휴대용: `ShisaPersonal-0.5.1-win-x64.zip`을 풀고 `ShisaPersonal.exe`를 실행합니다.
- 실행 중인 개인용 시사를 알림 영역에서 종료한 뒤 설치하세요. 기존 개인용 데이터/연결 설정/캐릭터는 `%USERPROFILE%\.shisa-personal`에 유지됩니다.
- 코드 서명은 없습니다. 캐릭터 그림/영상은 배포 파일에 포함하지 않습니다. 기존 캐릭터 이전 방법은 [0.5.0 릴리스 안내](https://github.com/Euiseon-Lee/shisa-agent/releases/tag/shisa-0.5.0-windows)를 참고하세요.

- 데스크톱 전체 테스트 866개 통과 / 2개 제외 / 실패 0개.

- 실제 Electron 화면에서 HEX 입력/적용과 기간 제목을 확인했습니다. 임시 Windows 바로가기로 아이콘/앱 식별자/고정 실행 경로 갱신을 검증했습니다.
