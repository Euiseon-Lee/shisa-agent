# 시사 개인용 v0.5.1 — Windows

v0.5.0 대비 변경 사항입니다. `추가`는 새 기능, `개선`은 기존 기능 보완, `변경`은 동작 변경을 뜻합니다.

## 「캘린더」 색상 설정

- `추가` **커스텀 색상 선택** — 기본 색상표 외에 색상 선택기와 6자리 HEX 코드로 원하는 색을 지정할 수 있습니다.
- `추가` **색상 미리보기와 적용** — 입력한 색을 미리 확인하고 「적용」 또는 Enter로 저장합니다. HEX 코드는 `#` 없이 입력해도 되며, 잘못된 코드는 저장하지 않습니다.
- `개선` **선택한 색상 반영** — 저장한 색은 재실행 후에도 유지되며, 캘린더 목록, 일정, 일정 상세 카드, 개요의 캘린더 목록에 반영됩니다. 「자동」을 선택하면 자동 색상으로 돌아갑니다.
- `개선` **일정 가독성** — 종일 일정의 글자색을 배경 밝기에 맞춰 조정합니다.

## 「통계」의 할 일 완료 기록과 집중 기록

- `개선` **완료 그래프 연결선 표시** — 날짜 영역에 마우스를 올려도 강조 배경이 연결선을 가리지 않도록 수정했습니다.
- `변경` **집중 기록 표시 정리** — 집중 시간 옆의 `↑` 표시와 「↑ 8시간 초과」 설명을 제거했습니다. 하루 8시간 기준과 실제 집중 시간, 100%를 넘는 비율은 유지합니다.

## 「할 일」의 예정일 선택

- `변경` **클릭으로 날짜 선택 창 열기** — 새 할 일 입력줄의 「오늘」 등 날짜 태그에 마우스를 오래 올려도 선택 창이 자동으로 열리지 않습니다. 클릭하면 하루, 기간, 반복 일정을 선택할 수 있습니다.

## 「패널 열기」

- `변경` **앱 최초 실행 화면** — 처음 실행하면 「개요」를 엽니다. 이후에는 기존처럼 마지막으로 보고 있던 메뉴를 표시합니다.
- `개선` **대체 메뉴 선택** — 저장된 메뉴가 없거나 숨겨져 있으면, 표시 중인 「할 일」 → 「오늘 할 일」 → 「개요」 순서로 엽니다.

## AI 없이 사용하는 로컬 모드의 할 일 안내

- `개선` **모든 미완료 할 일 확인** — 우선순위 1과 3만 확인하던 로컬 브리핑을 수정했습니다. 이제 모든 우선순위의 미완료 할 일을 예정일 기준으로 안내합니다.
- `개선` **예정일 순서로 표 정리** — 기존의 「예정일 / 상태 / 할 일」 표를 유지하면서, 날짜가 지난 항목 → 오늘 → 이후 예정일 → 날짜 없음 순서로 표시합니다. 진행 중 상태와 해당 할 일로 이동하는 링크도 표시합니다.
- `개선` **기간 / 반복 일정 반영** — 기간으로 설정된 할 일은 시작일과 종료일을 표시하고, 기간 중에는 오늘을 기준으로 정렬합니다. 반복 일정은 생성된 각 할 일의 예정일을 기준으로 안내합니다.
- `개선` **빈 목록 판단** — 모든 우선순위의 미완료 할 일을 확인한 뒤, 항목이 하나도 없을 때만 빈 목록으로 안내합니다.

## 브리핑의 메일 안내

- `개선` **메일 서비스 이름 표시** — 메일 안내에 실제 서비스 이름을 표시해 어떤 계정의 결과인지 알 수 있도록 했습니다. 조회에 실패한 계정은 ‘받은 메일 없음’ 안내 대상에 포함하지 않습니다.

## Windows 작업 표시줄과 바로가기

- `개선` **고정 아이콘에 캐릭터 반영** — 「앱 아이콘도 캐릭터로」 설정에 따라 작업 표시줄에 고정한 바로가기와 시작 메뉴, 바탕 화면 바로가기의 아이콘도 갱신합니다.
- `개선` **업데이트 후 실행 경로 유지** — 설치형 앱의 바로가기가 버전별 폴더 대신 고정된 실행 경로를 사용하도록 수정했습니다.
- `개선` **공식 앱과 개인용 앱 구분** — Windows가 공식 앱과 개인용 앱을 서로 다른 앱으로 인식하도록 수정했습니다.

## 날짜 / 기간 / 시간 표시

- [개요 / 할 일 / 오늘 할 일 / 캘린더] 하루 날짜는 `2026년 11월 18일 수요일` 형식으로 표시합니다.
- [캘린더 / 통계] 주간 기간은 `2026년 11월 16일 ~ 11월 22일`, 월간 제목은 `2026년 11월` 형식으로 표시합니다. 연도를 넘는 기간은 `2026년 12월 28일 ~ 2027년 1월 3일`처럼 양쪽에 연도를 표시합니다.
- [공통] 일반 날짜는 `11/18`, 요일이 필요한 날짜는 `11/18 수요일`로 표시합니다. 올해와 다른 해의 날짜는 `2027/01/03`처럼 연도를 함께 표시합니다.
- [통계] 그래프의 짧은 날짜는 `11/18 (수)`로 표시합니다.
- [공통] 숫자 날짜의 월과 일은 두 자리로, 한글 날짜는 앞에 0 없이 표시합니다.
- [공통] 상세 날짜와 시각은 `2026년 11월 18일 수요일 14:05`처럼 24시간제로 표시합니다. 「방금」, 「5분 전」, 「어제」 같은 최근 활동 안내는 유지합니다.

## 레이아웃 통일

- [캘린더 / 통계] 날짜 이동 영역을 `〈 날짜 또는 기간 〉` 형태로 통일했습니다.
- [캘린더 / 통계] 「오늘」 버튼을 보기 선택 그룹 앞에 독립적으로 배치했습니다. 캘린더는 `[오늘]  [일 / 주 / 월]`, 통계는 `[오늘]  [주 / 월]` 순서이며, 버튼 모양과 선택 표시를 통일했습니다. 캘린더는 저장된 보기가 없으면 기존처럼 「주」 보기로 열립니다.
- [개요 / 할 일 / 오늘 할 일 / 캘린더 / 통계] 상단 날짜의 글자 크기와 색상을 통일했습니다.
- [공통] 본문 시작 간격과 첫 제목 아래 간격을 공통으로 관리하도록 정리했습니다.
- [프로젝트] 「내가 만든 프로젝트」의 글자 크기, 색상, 굵기를 개요의 상단 날짜와 맞추고, 불필요한 위 여백을 제거했습니다.
- [캘린더] HEX 입력창에 앱 기본 글꼴을 적용했습니다.
- [통계] 완료 기록과 집중 기록에 마우스를 올리면 같은 색상의 배경과 굵은 날짜를 표시합니다. 완료 기록은 해당 날짜의 점도 강조하며, 날짜와 완료 개수의 글자색은 유지합니다.
- [모델] 「설정 열기」 텍스트 버튼을 상단과 같은 톱니바퀴 아이콘으로 바꿨습니다.
- [사이드바] 「설치」 메뉴를 목록의 최하단으로 옮겼습니다.

## 문구 변경

- [공통] 할 일과 코드 승인 대기 관련 용어를 통일했습니다.
- [개요 / 브리핑 / 알림] 일정과 할 일이 없을 때의 안내를 자연스럽게 다듬었습니다. 기존에 저장된 브리핑과 알림의 일부 이전 용어도 변경된 표현으로 표시합니다.
- [통계] 하루 기록 제목을 날짜와 요일이 명확하게 보이도록 정리했습니다.
- [모델] AI와 모델 선택, 응답 방식 설명을 다듬고, 「정해진 말」을 「설정된 말투」로 변경했습니다. 버튼과 상태 안내도 이해하기 쉬운 표현으로 정리했습니다.
