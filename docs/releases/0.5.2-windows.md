# 시사 개인용 v0.5.2 — Windows

v0.5.1 대비 변경 사항입니다. `추가`는 새 기능, `개선`은 기존 기능 보완, `변경`은 동작 변경을 뜻합니다.

## 「할 일」의 출처 표시

- `변경` **출처를 글자로만 표시** — 출처 이름 뒤의 태그 배경을 제거했습니다.
- `추가` **업무 메일과 개인 메일 구분** — 설정에서 메일 계정의 용도를 지정하면 할 일에 「업무 메일」 또는 「개인 메일」로 표시합니다. 용도를 확인할 수 없으면 「메일」로 표시합니다.
- `개선` **AI 도구 이름 표시** — 작업 기록을 가져온 도구에 따라 「Claude Code」 또는 「Codex」로 표시합니다. 도구를 확인할 수 없으면 「AI」로 표시합니다.
- `변경` **출처 이름 정리** — 일반 출처는 한국어로 표시하고, Slack과 Jira 등 서비스 이름은 그대로 사용합니다.

## 「할 일」의 반복 업무

- `추가` **반복 업무를 모아 보는 영역** — 「나중에」와 「날짜 없음」 사이에 「반복」 영역을 추가했습니다. 같은 반복 업무가 날짜별로 여러 줄 나타나는 대신, 일정 하나당 한 줄로 표시합니다.
- `변경` **반복 일정 관리와 완료 처리 구분** — 반복 영역에서는 체크박스 없이 일정을 관리합니다. 오늘 해야 할 업무와 날짜가 지난 미완료 업무는 기존처럼 해당 영역에서 체크하여 완료합니다. 앞으로 생성된 반복 업무가 「이번 주」와 「나중에」에 길게 나열되지 않도록 정리했으며, 진행 중인 항목은 유지합니다.
- `개선` **반복 요일을 알기 쉽게 표시** — 월요일부터 금요일까지 선택하면 「평일」, 토요일과 일요일은 「주말」, 모든 요일은 「매일」로 표시합니다. 일부 요일만 선택하면 선택한 요일을 표시합니다.
- `개선` **다음 날짜 안내** — 반복 주기 옆에 「다음 11/20」처럼 다음 예정일을 표시합니다. 매일 반복하는 업무는 다음 날짜를 생략하고, 아직 시작하지 않은 업무는 시작 날짜를 표시합니다.
- `추가` **반복 일정 변경과 종료** — 반복 업무의 메뉴에서 일정을 변경하거나 반복을 종료할 수 있습니다. 반복을 종료해도 이미 생성된 할 일과 완료 기록은 남습니다.
- `변경` **반복 업무에 민트색 적용** — 반복 영역과 반복 아이콘을 민트색으로 표시합니다. 새 할 일을 추가할 때도 반복을 선택하면 날짜 태그가 민트색으로 바뀝니다. 오늘 할 일 등 날짜별 목록에서는 기존 날짜 색상을 유지하고, 태그 안의 반복 아이콘으로 구분합니다.

## 「할 일」 목록의 스크롤과 접기

- `추가` **반복 목록 내부 스크롤** — 최대 5개 행 높이로 표시하고, 6개부터 목록 안에서 스크롤합니다.
- `추가` **날짜 없음 목록 내부 스크롤** — 최대 10개 행 높이로 표시하고, 11개부터 목록 안에서 스크롤합니다.
- `추가` **최근 7일 완료 목록 내부 스크롤** — 최대 10개 행 높이로 표시하고, 11개부터 목록 안에서 스크롤합니다.
- `개선` **긴 제목에 맞춘 높이 조절** — 제목이 여러 줄이어도 실제 행 높이에 맞춰 표시합니다. 영역 제목은 스크롤되지 않고 목록만 움직입니다.
- `변경` **최근 7일 완료는 기본으로 접어서 표시** — 앱을 열면 완료 목록이 접혀 있습니다. 제목을 클릭하거나 키보드의 Enter 또는 Space를 누르면 펼치거나 접을 수 있습니다.
- `변경` **완료 목록에 삼각형 표시** — 색상 동그라미 대신 「관련없음」과 「휴지통」처럼 회색 삼각형으로 접힘 상태를 표시합니다. 제목 옆에서 완료 개수도 확인할 수 있습니다.
- `개선` **스크롤 위치 유지** — 목록이 갱신되거나 접었다 펼쳐도 보던 스크롤 위치를 유지합니다.

## 「캘린더」의 꺼 둔 항목 숨기기

- `변경` **꺼 둔 캘린더는 화면에서 숨김** — 사용하지 않는 캘린더와 그 일정을 캘린더 화면에서 숨깁니다. 이름 옆에 「꺼 둠」 표시가 붙은 항목도 더 이상 남지 않습니다.
- `개선` **필요할 때 다시 켜기** — 캘린더 연결 정보는 유지되므로 설정에서 다시 켤 수 있습니다.

## 「통계」의 오전과 오후 집중 시간

- `개선` **집중 시간을 한 줄로 표시** — 오전과 오후 집중 시간 카드에서 「1시간 37분」처럼 시간과 분을 한 줄로 표시합니다.
- `변경` **시간을 오른쪽으로 정렬** — 카드 제목은 왼쪽, 시간은 오른쪽에 배치해 높이와 여백을 줄였습니다. 다른 통계 항목의 모양은 유지합니다.

## Windows 개인용 배포 정보

- `개선` **제작자 정보 수정** — 개인용 설치 파일의 제작자를 「Euiseon-Lee」로 표시하도록 수정했습니다.
- `개선` **설치 목록 아이콘 경로 수정** — 개인용 앱의 설치 목록 아이콘을 개인용 저장소에서 가져오도록 수정했습니다.
