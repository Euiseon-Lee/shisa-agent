# 개인용 Shisa Agent 변경 사항

공식 0.4.0 소스를 바탕으로 날짜별 할 일 관리, 집중 통계, 알림과 설정 화면을 개인용으로 개선했어요. 기존 0.3.3 데이터와 캐릭터는 별도 사용자 폴더로 가져와 사용해요.

## 할 일과 일정

- 예정일을 기준으로 미완료 / 오늘 / 이번주 / 나중에 / 날짜 없음으로 묶어요. 미완료는 항상 펼치고, 정확한 날짜는 항목의 태그에서 확인해요.
- 날짜 선택창에서 하루 / 기간 / 반복을 선택해요. 하루는 오늘을 기본값으로 사용하고 「날짜 없음」으로 해제할 수 있어요.
- 기간은 하나의 할 일이 기간 내 날짜에 표시되며, 완료 처리하면 전체 완료돼요. 반복은 선택한 요일마다 별도 항목을 만들고 각 항목을 따로 완료해요.
- 반복은 시작일과 종료일을 항상 표시하며 기본 종료일은 시작일 14일 후예요. 종료일 `9999-12-31`은 종료 없는 반복을 뜻해요.
- 날짜 태그와 헤더 색을 통일했어요. 미완료는 코랄, 오늘은 보라, 이번주는 노랑, 나중에는 주황, 날짜 없음은 연한 파랑을 사용해요.
- 「⋯」 메뉴에서 날짜 변경, 관련없음, 삭제를 실행해요. 관련없음은 자동 재등록 제외를 위한 상태이며 휴지통과 별도로 복원하거나 비울 수 있어요. 제외 기록을 영구 삭제하면 다시 자동 등록될 수 있어요.
- 최근 7일 완료는 실제 완료 처리 시각으로 정렬해요. 일반적인 제목이나 메모 수정은 완료 시각을 바꾸지 않아요.
- 드래그와 키보드 순서 변경은 같은 예정일 안에서만 적용해요. 별도 순서 필드를 사용하므로 우선순위나 예정일, 반복 설정을 바꾸지 않아요.

## 통계와 집중

- 할 일과 오늘 할 일의 중복 통계를 별도 「통계」 메뉴로 모았어요.
- 완료 기록과 집중 기록은 하나의 주/월 범위와 선택 날짜를 공유해요. 미래 날짜의 기록은 비우되 날짜 위치는 유지해요.
- 주간 완료 선 그래프의 높이와 점은 해당 날짜의 완료 개수를 표시해요. 하루 10개 제한은 사용하지 않아요.
- 주간과 월간 집중 기록은 오전/오후 도넛 차트로 표시해요. 가운데 비율은 하루 8시간을 기준으로 하며, 초과 시간도 실제 값으로 확인할 수 있어요.
- 날짜를 선택하면 오전/오후 집중 시간, 그날 완료한 할 일과 진행 중으로 기록된 할 일을 확인해요. 예정일이 그날이라는 이유만으로 진행 중 목록에 넣지는 않아요.
- 요약 카드와 오전/오후 카드에서 시간과 분이 함께 있으면 `18시간`과 `20분`처럼 단위별로 두 줄에 표시해요. 숫자와 단위는 분리되지 않아요.
- 모든 메뉴에서 상단 「집중하기」를 사용할 수 있어요. 캐릭터 우클릭 메뉴에는 「패널 열기」 위에 「집중 시작」을 표시하고, 집중 세션이 있으면 숨겨요.

## 브리핑과 알림

- 최근 브리핑의 할 일은 예정일 / 상태 / 할 일 표로 표시해요. 문장형 목록 뒤에 설명이 붙는 경우도 표로 변환해요.
- 예정일 열 너비를 줄이고 기간은 시작일과 종료일을 두 줄로 표시해요. 표 헤더는 중앙 정렬해요.
- 할 일 알림에는 날짜와 한글 출처명을 사용하고, 긴 제목은 줄바꿈과 내부 스크롤로 확인해요.
- 확인이 필요한 알림은 「확인」을 누르기 전까지 보관하고 앱을 다시 실행해도 남아요. 여러 알림은 페이지로 넘겨 봐요.
- 정보를 모으는 중이라는 안내나 단순 인사처럼 일시적인 메시지는 확인 대기 알림으로 쌓지 않아요.

## 화면과 설정

- 개요, 할 일, 오늘 할 일에 일관된 오늘 날짜 표기를 사용해요. 카드 배경과 간격, 숫자 정렬도 맞췄어요.
- 「좌측 메뉴 표시」에서 메뉴 표시 여부와 순서를 조정해요. 설치와 개요는 고정이고 다른 메뉴는 개요 아래에 배치돼요. 오늘 할 일 메뉴는 기본 숨김이에요.
- 설정 문구는 해요체와 「」 표기로 정리하고, 「저장소」, 「로컬 정보」, 「앱 정보」 등의 용어를 통일했어요.
- AI 모델, 연결, 날씨, 일정과 오늘 할 일 알림의 설명 및 배치를 정리했어요. 분 단위 알림 간격은 읽기 쉬운 시간/분으로 표시해요.

## 개인용 빌드와 마이그레이션

저장소 루트에서 다음 명령으로 Windows x64 설치파일과 휴대용 ZIP을 만들어요.

```powershell
node windows/dist-win.mjs --personal --arch=x64
```

결과는 `desktop/dist/win-personal/`에 생성돼요. 개인용 앱은 `ShisaPersonal`이라는 별도 이름과 포트 `47834`를 사용하며, 데이터는 `~/.shisa-personal`에 보관해요. 공식 앱 업데이트로 개인용 변경이 덮이지 않도록 공식 업데이트 안내를 끄도록 했어요.

기존 사용자 데이터가 없는 최초 이전은 아래 명령으로 실행해요. `--assets`에는 기존 공식 앱의 `resources/assets` 폴더를 지정해요.

```powershell
node windows/migrate-personal.mjs --assets="<기존 공식 앱 resources/assets 경로>"
```

마이그레이션은 공식 DB를 읽기 전용으로 열어 일관된 스냅샷을 만들고, 원본과 백업을 보존해요. 개인용 대상 폴더가 이미 있으면 덮어쓰지 않아요. 설정과 캐릭터는 별도 사용자 폴더에 복사하며, 설치파일과 Git에는 넣지 않아요. 두 앱 사이의 지속적인 동기화 기능은 아니에요.

과거 완료 시각은 완료 일지를 우선 사용해요. 일지가 없는 기록은 마지막으로 알려진 수정/생성 시각을 사용하므로 정확한 과거 시각을 복원할 수는 없어요. 진행 중 이력도 기록을 시작한 이후부터 확인할 수 있어요.

## 검증

2026-11-18 Windows 환경에서 다음 검증을 진행했어요.

- 백엔드 타입 검사 및 전체 테스트: 1,133개 통과, 9개 제외, 실패 없음.
- 데스크톱 전체 테스트: 863개 통과, 1개 제외, 실패 없음.
- 마지막 통계 시간/분 줄바꿈 수정 후 통계 화면 테스트 3개 재실행 및 통과.
- 제외 항목은 Windows의 POSIX/파일 링크 조건, 사용할 수 없는 OpenSSL 또는 Git 태그 등 환경 조건 때문이에요.
- 마이그레이션 DB 무결성, 기존 데이터 보존, 캐릭터 파일 해시, 배포본 런타임의 집중 기록 조회를 확인했어요.
- 개발 앱에서 브리핑 표의 표시, 예정일 열 108px, 헤더 중앙 정렬을 확인했어요.

시간/분 줄바꿈 변경은 소스와 설치된 개인용 앱에 반영했어요. 이 변경 이전에 생성한 설치파일/ZIP에는 포함되지 않으므로, 새 설치파일이 필요하면 위 빌드 명령을 다시 실행해요.

개인 데이터, 개발 예시 DB, 캐릭터 원본 이미지/영상, 설치파일과 로컬 도구는 Git 업로드 대상에서 제외해요.
